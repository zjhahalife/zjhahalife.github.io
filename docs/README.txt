Zhou Jun — Artist Website

Extract the entire ZIP, then open index.html in a web browser.
Keep the assets and works folders beside index.html.

Includes 54 works, 79 documentation images, 13 complete work texts,
5 playable videos, 12 exhibition records and 2 self-published books.
Use Works to browse or filter the archive. Click an image to enlarge it.
On touch devices, swipe horizontally in the enlarged gallery.

The website works locally without installing any software or dependencies.
Website address: https://zjhahalife.github.io/
